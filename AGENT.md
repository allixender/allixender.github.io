# Migration Plan: Jekyll to Hugo

## Overview
Migrate the existing Jekyll-based blog to Hugo while preserving the design and card-based listing.

## Current Structure Analysis
- **Jekyll Version**: Uses Skinny Bones template
- **Content**: Posts in `_posts/articles/` with front matter (YAML)
- **Layouts**: Uses `_layouts/` and `_includes/` for templates
- **Assets**: CSS, JS, images in respective directories
- **Configuration**: `_config.yml` with site metadata

## Hugo Setup Plan

### 1. Project Structure
```
hugo-blog/
├── config.toml          # Hugo configuration
├── content/             # Markdown content
│   └── articles/        # Migrated posts
├── layouts/             # Custom templates
│   ├── _default/        # Base templates
│   ├── partials/        # Reusable components
│   └── index.html        # Homepage template
├── static/              # Static assets
│   ├── css/             # Stylesheets
│   ├── js/              # JavaScript
│   ├── images/          # Images
│   └── fonts/           # Fonts
├── themes/              # Optional: Third-party themes
└── public/              # Generated output
```

### 2. Configuration Migration
- Convert `_config.yml` to `config.toml`
- Key mappings:
  - `title` → `title`
  - `description` → `description`
  - `url` → `baseURL`
  - `permalink` → `permalinks`

### 3. Content Migration
- Move posts from `_posts/articles/` to `content/articles/`
- Update front matter format (TOML/JSON/YAML)
- Preserve:
  - `title`, `date`, `categories`, `tags`
  - Custom fields: `image.teaser`, `modified`

### 4. Template Migration
- **Layouts**:
  - `default.html` → `layouts/_default/baseof.html`
  - `archive.html` → `layouts/_default/list.html`
  - `article.html` → `layouts/_default/single.html`
- **Partials**:
  - `post-grid.html` → `layouts/partials/post-card.html`
  - `header.html` → `layouts/partials/header.html`
  - `footer.html` → `layouts/partials/footer.html`

### 5. Asset Handling
- Copy static files to `static/` directory
- Update references in templates to use `{{ .Site.BaseURL }}`

### 6. Build & Verify
- Run `hugo server` for local testing
- Check:
  - Card-based listing on homepage
  - Individual post pages
  - RSS feed generation
  - Static asset paths

## Tools Required
- Hugo Extended v0.156.0 (available at `~/.local/bin/hugo`)
- Basic text editor for file conversions

## Risks & Mitigations
- **Template Syntax**: Hugo uses Go templates vs Jekyll's Liquid
  - Mitigation: Use Hugo's template documentation
- **Front Matter**: Different handling of custom fields
  - Mitigation: Test with sample posts first
- **Asset Paths**: Different URL handling
  - Mitigation: Use `{{ .Site.BaseURL }}` consistently
